# Security Policy 🛡️

## Supported Versions

The following versions of **Mene Monitor** are currently supported with security updates:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

---

## Reporting a Vulnerability

We take the security of **Mene Monitor** seriously. If you discover a security vulnerability or security bug, please **do not open a public GitHub issue**.

### Disclosure Process

1. **Private Reporting**: Send an email describing the vulnerability to **security@mene.app** or submit a private security advisory on GitHub.
2. **Details to Include**:
   - Description of the issue and potential impact.
   - Step-by-step instructions to reproduce the issue.
   - Affected device configurations, Android API levels, or components.
3. **Response Time**: We aim to acknowledge receipt of security reports within **48 hours** and provide a patch or resolution timeline within **7 business days**.

Thank you for helping keep Mene Monitor safe and secure for everyone!
